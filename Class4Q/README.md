# 3. recover
1. 优先级从高到低：
    - ==
    - &
    - &&
2. 为什么 recover 中 while 循环结束后不需要再处理剩余数据？
    - 在 CS50 的 recover 题目中，输入文件 card.raw 是直接以 512 字节块为单位从存储设备拷贝的镜像，其大小恰好是 512 的整数倍。因此，文件末尾不会存在“不足 512 字节”的部分，每次 fread 要么读取完整 512 字节，要么返回 0（文件结束）。如果没说raw按块存储，那就是要进行后续处理的。
3. fread(buffer, sizeof(buffer), 1, file) == 1 与 fread(buffer, 1, BLOCK_SIZE, file) == BLOCK_SIZE 作为循环条件有什么区别？
    - 在文件大小是 512 字节整数倍的前提下，两者完全等价，因为每次都能完整读取一个块，返回值分别为 1 或 512，循环条件都成立；文件结束时返回值分别为 0 或 0，循环退出。即在对齐条件下没有区别，通用场景推荐使用 fread(buffer, 1, size, file) 配合 > 0 判断以处理不完整读取。
